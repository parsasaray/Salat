# Salat — A Clean, Reliable Prayer Reminder App

What started as a simple personal tool is now the go-to app for my entire community, and many say it's the best one they’ve used.
They wanted no ads, no distractions, no unnecessary features. Just a fast, accurate, and minimal, yet useful prayer utility.

Core Features
	•	Accurate daily prayer times at a glance (with widget support too)
	•	Instant Qibla direction compass at a glance
	•	Minimalistic UI
	•	Convenient widget display

Purpose & Design Principles
	•	Instant access to what you need, meaning no digging through menus
	•	Visual clarity so you can peek and move on
	•	Lightweight & performance-focused
